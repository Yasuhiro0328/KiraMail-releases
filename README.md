# KiraMail

**いくつものメールアドレスを、1つの画面で。返信は AI が下書きし、あなたが確かめてから送る、Windows のメールソフトです。**

[ダウンロード（最新版）](https://github.com/Yasuhiro0328/KiraMail-releases/releases/latest)　｜　[利用規約](LICENSE.md)　｜　[プライバシーポリシー](https://haga-sys.jp/kiramail-privacy/)　｜　[お問い合わせ](https://haga-sys.jp/contact/)

---

## できること

- **複数のメールアドレスを1つの画面で。** 受信トレイをまとめて見ることも、アドレスごとに見ることもできます
- **返信の下書きを AI が作ります。** 送る前に必ずあなたが確かめます。確かめていないメールが送られることはありません（自動で送る設定は、はじめから用意していません）
- **要約・翻訳。** 長いメールを3行にまとめたり、外国語のメールを日本語にしたりできます
- **振り分け。** 差出人や件名などの条件で、届いたメールをフォルダーへ分けます
- **送信の取り消しと予約送信。** 送ったあと10秒は取り消せます。日時を決めて送ることもできます
- **Thunderbird に近い操作。** キー操作やメニューの並びを Thunderbird にそろえています。乗り換えても迷いにくくしています
- **HTML メールの画像は、押すまで読み込みません。** 開いたことが相手に伝わるのを防ぎます

## 動く環境

- Windows 10 / 11（64 ビット）
- IMAP または POP3 で受信でき、SMTP で送信できるメールアドレス（プロバイダーのメール、Gmail、Yahoo!メール、iCloud メールなど）

## ダウンロードと入れ方

1. [配布ページ](https://github.com/Yasuhiro0328/KiraMail-releases/releases/latest)の「Assets」から、`KiraMail-（版番号）-x64.exe`（例：`KiraMail-0.12.0-x64.exe`）をダウンロードします
2. ダウンロードしたファイルを開きます
3. **「Windows によって PC が保護されました」と出たときは**、「詳細情報」を押してから「実行」を押してください
   - KiraMail にはまだ「発行元を証明する署名」が付いていないため、Windows が念のため確認を出します。配布ページから入手したものであれば、そのまま進めて問題ありません
   - ブラウザーが「一般的にダウンロードされていません」と出したときも、「保存」または「保持する」を選んでください
4. 利用規約が表示されます。お読みいただき、「同意する」を押すと先へ進みます
5. 入れる場所を選んで「インストール」を押します。終わると KiraMail が使えるようになります

はじめて起動したら、メールアドレスとパスワードを入れるだけで、受信と送信の設定を調べて登録します。

### Gmail をお使いの方へ

Gmail は、普段のパスワードではログインできません。次のどちらかで登録します（アカウントを追加する画面にも手順を出します）。

- **Google でログイン**：ご自身の Google Cloud で OAuth クライアント（種類：デスクトップ アプリ）を作り、そのファイルを選ぶと、既定のブラウザーで Google にログインします。KiraMail に Google のパスワードは入れません
- **アプリ パスワード**：Google アカウントで2段階認証をオンにしてから「アプリ パスワード」を作り、そのパスワードを入れます

### よくある操作

- **メニューを出す**：メニューバーは初めは隠れています。Alt キーを押すと出ます
- **パスワードを変えた**：「ツール → アカウント設定…」で、そのアカウントの「サーバー設定」に新しいパスワードを入れて「接続を確認して保存」を押します
- **アカウントの順番を変える**：「ツール → アカウント設定…」の左下「アカウントの並び順」の［上へ］［下へ］で変えます（アカウントの行をつかんで動かすか、Alt+↑・Alt+↓ でも変えられます）
- **設定が見つからない**：設定の画面の上の「設定を検索」に言葉（例：パスワード・並び替え・文字サイズ）を入れます

## 無料版で使える範囲

- **登録できるメールアカウントは2つまで**です
- それ以外の機能（AI の返信の下書き・要約・翻訳・振り分け・送信の取り消し・予約送信など）は、**すべて無料版で使えます**
- アカウントの数に制限のない有料版は、ただいま準備中です

AI の機能を使うときの料金は、ご自身でご用意いただく AI のサービスの料金です（下の「AI の機能について」）。KiraMail に料金はかかりません。

## できないこと・ご注意

- **Microsoft のメール（Microsoft 365・Outlook.com・Hotmail）は、今の KiraMail ではつながりません。** Microsoft が、ID とパスワードでメールソフトからつなぐ方法を終了したためです
- **KiraMail には、まだ発行元の署名がありません。** 入れるときと、はじめて起動するときに、Windows が「発行元不明」の確認を出すことがあります（進め方は「ダウンロードと入れ方」の3）
- メールは、お使いの PC の中に保存します。KiraMail をアンインストールしても、メールのデータ（`%APPDATA%\KiraMail`）は残ります。完全に消したいときは、アンインストールのあとにこのフォルダーを削除してください

## AI の機能について

- AI の機能は、**最初は使えない状態**です。使うときは、設定の「AI」で、どこに頼むかを選びます
  - Anthropic または OpenAI の API キー（使った分だけ、各社の料金がかかります）
  - この PC に入っている Claude Code または Codex（ご自身の Claude や ChatGPT の契約の範囲で動きます）
- AI の機能を使うと、**メールの本文などが、選んだ AI の提供元（Anthropic または OpenAI）へ送られます。** Claude Code・Codex を選んだときも、それぞれを通じて Anthropic・OpenAI へ送られます。送るのは、使った機能に必要な範囲のメールです。くわしくは[プライバシーポリシー](https://haga-sys.jp/kiramail-privacy/)をご覧ください
- メールのパスワードやアドレス帳の一覧を、AI へ送ることはありません
- AI が作った下書きは、あなたが確かめて「送信する」を押すまで送られません。AI の答えには誤りが含まれることがあります。送る前に、宛先と内容を確かめてください

## メールを Markdown で残す・Claude に頼む（どちらも入れたときだけ）

どちらも**最初は切**です。入れなければ、何も変わりません。

**Markdown に保存**：届いたメール・送ったメールを1通ずつ文字のファイル（.md）にして、この PC のフォルダーに保存します。Obsidian などのノートのアプリや AI から過去のメールを探せます。

- 入れる：設定の左下「アカウント設定」→ アカウントの「Markdown に保存」で「このアカウントのメールを Markdown でも保存する」にチェックし、確認で「保存する」を押します（アカウントごと）
- 止める：同じチェックを外します。それまでに保存したファイルは残ります
- ファイルは外へ送りません。ただし、OneDrive などの同期の中のフォルダーを選ぶと、そのサービスへ送られます（選ぶときに注意を出します）

**Claude に頼む**：振り分けのルールに一致したメールを、この PC の Claude Code に1通ずつ渡して、要約などを頼みます。Claude Code（ご自身の Claude の契約）が要ります。

- 入れる：設定の「AI」→「Claude に頼む」で「振り分けルールの「Claude に頼む」を動かす」にチェックし、何を渡すかを確かめて「入れる」を押します。そのあと、振り分けのルールの動作で「Claude に頼む」とひな形を選びます
- 止める：同じチェックを外します（ルールに一致しても何もしなくなります）
- ルールに一致したメールと、右クリックなどで手で頼んだメールの中身（差出人・宛先・日時・件名・本文と、添付ファイルの名前と大きさ）は、Claude Code を通じて Anthropic へ送られます。ソースを読むひな形では、Claude が読んだソースの部分も、「過去のメールも見せる」を入れた相手では、その相手との過去のメール（30 通まで）も送られます（添付ファイルの中身は渡しません）。Claude は読むだけで、**メールを送信しません**。返信の下書きを作っても、送るのはあなたが確かめて「送信する」を押したときだけです
- 差出人で絞るルールは、受信サーバーが差出人を確かめた結果（認証）が通ったメールでだけ動きます。`co.jp` のような多くの会社が使う共通の部分だけでは、差出人を指定したことになりません

## 新しい版（KiraMail の中で更新）

0.15.0 から、新しい版を KiraMail の中で入れられます。**ダウンロードも入れ替えも、あなたが押したときだけ**行います。

1. 新しい版が出ると、画面の下に「新しいバージョン ○○ があります」と出ます。［ダウンロード］を押すと、ダウンロードを始めます（［中止］で止められます）
2. 終わると「○○ に更新する準備ができました」と出ます。［再起動して更新］を押し、確認の小窓でもう一度［再起動して更新］を押すと、KiraMail を閉じて入れ替え、もう一度開きます（1分ほど）
   - 書きかけのメールがあれば、保存するか先にお聞きします。送信待ちのメールは、送り終えてから入れ替えます
   - 入れ替える前に、メールのデータの控えを作ります。メールと設定はそのまま残ります
3. 開き直すと、画面の下に「○○ に更新しました」と出ます

- 確かめるのは、KiraMail を起動したときと、起動している間は24時間おきです。「ヘルプ → KiraMail について」の［更新を確認］でも確かめられます
- 確かめるときは、GitHub から新しい版の情報（版番号・ファイルの名前と大きさ・照合の値）を読むだけです。送るのは、アプリの名前「KiraMail」と、通信の仕組みで自動で付く一般的な情報（言語の設定〔日本語など〕、受け取れるデータの形式など）だけで、メールやアカウントの情報、この PC やあなたを見分ける番号は送りません
- ダウンロードしたファイルは、配布元の照合の値と一致したときだけ使います。前の版との違う所だけをダウンロードできるときは、そうします
- 自動で確かめるのは、設定の「一般 → KiraMail の更新」の「新しいバージョンを自動で確認する」で止められます（止めても、手で確かめられます）

**0.14.2 以前をお使いの方へ**：0.14.2 以前の KiraMail には、この仕組みがありません。今回だけ、この配布ページから 0.15.0 以降をダウンロードして、そのまま上から入れてください。メールと設定は引き継がれます。次の版からは KiraMail の中で更新できます。

**うまくいかないとき**：お知らせの［配布ページを開く］から、いつでも手で入れられます。入れ替えの途中で電源が切れるなどして KiraMail が開かなくなったときも、この配布ページから同じ版をもう一度入れてください（メールと設定はそのまま残ります）。

**前の版に戻したいとき**（新しい版で困ったことが起きたとき）：

1. KiraMail を終了します（画面の右下の KiraMail のアイコンを右クリックして「終了」。窓を閉じるだけでは終わりません）
2. [リリースの一覧](https://github.com/Yasuhiro0328/KiraMail-releases/releases)の前の版の「Assets」から、`KiraMail-（版番号）-x64.exe` をダウンロードして、そのまま上から入れます。メールと設定はそのまま残ります。前の版は、新しい版が整えたメールのデータをそのまま開けるので、多くの場合は、ここまでで元どおり使えます
3. それでも KiraMail が開かない・メールの表示がおかしいときだけ、KiraMail が作っておいた控えに戻します
   - KiraMail を終了してから、エクスプローラーのアドレス欄に `%APPDATA%\KiraMail` と入れて開きます
   - `kiramail.db` と、あれば `kiramail.db-wal`・`kiramail.db-shm` を、新しく作ったフォルダー（例「新しい版のデータ」）へ移します（消さずに残しておきます）
   - `移行前のバックアップ` フォルダーの中から、戻したい版に合う控えを選んで `%APPDATA%\KiraMail` に写し、名前を `kiramail.db` に変えます。控えの名前は `kiramail_<版>_<日時>.db` です
     - **0.14.2 以前に戻すとき**：`kiramail_0.15.0_<日時>.db`（後ろに `_更新前` が付かない物）。0.15.0 を初めて起動したときに、メールのデータを新しい形に移す直前の姿を控えた物です
     - **0.15.0 以降の版に戻すとき**：`kiramail_<戻したい版>_<日時>_更新前.db` のうち、いちばん新しい物。KiraMail の中で次の版に更新する直前の姿を控えた物です
     - 控えは新しい物から3つだけ残ります（古い物は消えます）
   - KiraMail を起動します。控えを作った後に受け取ったメール・書いた下書き・変えた設定は、控えを作った時点に戻ります

前の版を使った後で、もう一度新しい版に更新したときは、前の版で振り分けルールの「フォルダーへ移動」の行き先を変えていたら、振り分けルールの画面で行き先を選び直してください（新しい版は行き先を場所で覚えていて、前の版で変えた名前を読みません）。
